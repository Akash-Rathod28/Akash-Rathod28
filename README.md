## 🚀 ARCHITECTURAL BUILDS & SYSTEMS

### 🔍 1. Document Question-Answering & Semantic RAG API
> *High-throughput retrieval pipeline engineered to eliminate document lookup latency.*
* **Ingestion Pipeline:** Splits complex PDFs into structured text chunks and generates dense embedding vectors for search.
* **Vector Indexing:** Leverages FAISS for lightning-fast sub-second similarity matching.
* **API Security & Limits:** Asynchronous FastAPI microservices enforced via strict Pydantic models and request rate limiting.
* **Stack:** `Python`, `FastAPI`, `PyTorch`, `FAISS`, `PostgreSQL`

### 🛒 2. E-Commerce Backend & Cloud Infrastructure
> *Enterprise-grade relational backend deployed onto cloud servers.*
* **Relational Schema:** Normalized PostgreSQL architecture tracking users, complex product catalogs, carts, and order workflows.
* **Authentication:** Stateless JWT generation paired with robust bcrypt cryptographic hashing.
* **Cloud Orchestration:** Containerized via Docker Compose and live-deployed to an AWS EC2 Ubuntu instance.
* **Stack:** `FastAPI`, `PostgreSQL`, `SQLAlchemy`, `Docker Compose`, `AWS EC2`

### 📊 3. Machine Learning Training & Telemetry Suite
> *Data reproducibility workflows and automated server health monitoring.*
* **Model Pipeline:** Tabular data pre-processing via Pandas feeding Scikit-Learn baselines and custom PyTorch neural networks tracked via MLflow.
* **System Telemetry:** Autonomous cron daemon sampling CPU usage, memory load, and open port configurations.
* **Stack:** `PyTorch`, `Scikit-Learn`, `MLflow`, `Bash`, `Ubuntu Linux`
